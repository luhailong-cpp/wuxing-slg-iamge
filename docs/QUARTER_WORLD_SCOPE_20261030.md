# 四分之一世界地图制作合同

用户指定地图仅率土的四分之一。采用网易官方应用介绍的225万格口径，四分之一为562500格；本项目选择750×750格的方形世界数据尺寸。750是本项目制作选择，不声称已经测得率土各赛季的边长。横版描述客户端视口，世界数据采用方形不影响横屏。

来源：[网易官方云游戏介绍](https://apps.apple.com/cn/app/%E4%BA%91-%E7%8E%87%E5%9C%9F%E4%B9%8B%E6%BB%A8/id1658292466)，2026-10-30实际打开。其他赛季可能使用不同地图，当前合同以该225万格口径为参考。

数据按32×32格分为24×24、共576区块，最后一行/列各14格。分块面积校验为562500，没有生成576张美术图，也不为每个格子重复生成单独图片。地形采用可复用图集，布局、城池和关隘另由世界数据安排。

现有1672×941图只保留为区域场景布局草案：5个据点、4座桥、2处关隘，不按该图比例直接放大为整个世界。世界拓扑、细节地形、无缝性、通行、缩放和Unity接入尚未完成。
