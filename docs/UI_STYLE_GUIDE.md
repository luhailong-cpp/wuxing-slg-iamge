# 道家 Q 版 UI 与角色视觉规范

## 先看原图

主参考为[邮件界面](../designs/mail-ui-v1/01-mail-event.png)与[组队界面](../designs/team-ui-v2/team-ui-v2.png)。开始 UI 制作、AI 修改或切片前实际查看两张图，再看同功能已确认设计。生成时按任务需要实际附上主参考，明确每张图用于风格、布局还是人物身份。

这两张图的配色、材质、控件层级和完成度优先于文字概括及其他游戏截图。角色、NPC、怪物、宠物延续同一画法；具体身份、服装、武器、表情和姿态依当前角色参考确定。

## 统一视觉与控件层级

- **色彩与材质：** 玉绿、青绿为主色，象牙米白及暖米色纸绢用于大面积面板，暖金细边与柔和雕饰协调。朱砂、红穗、桃花粉和灯笼暖光少量点缀，文字区保持清楚。
- **形状与画法：** 框板与按钮圆润饱满，云纹和如意卷边柔和，手绘明暗细腻，金玉材质适度。保持高清完成度，避免塑料高光、粗糙拼贴、模糊拉伸和密集噪点。
- **层级：** 玉绿金边用于标题牌、主要操作与选中态；米白底用于正文、列表、卡片和次要操作。金色细分隔、留白和对齐服务于清晰阅读；重要状态同时依靠文字或图标表达。
- **装饰：** 太极、葫芦、玉珠、流苏、云气、仙山亭阁按用途适量使用。春节、元宵、中秋元素可自然融入，保持信息和操作无遮挡。
- **文字：** 中文可读，标签、数值、状态和操作符合任务。主参考中的测试数据、角色姓名、活动日期和标题不自动沿用为新成品文案。
- **人物：** 大头短身、圆润表情，服饰和法器有清楚层次；保留各角色身份特征，避免写实人物和统一套脸。

## 参考用途与制作合同

「率土之滨」等外部游戏默认提供功能、内容和布局参考，成品画法采用上述道家 Q 版。正式游戏名、文案与状态按当前任务指定，避免把素材分类名称自动画成产品标题。

每个界面或角色任务先明确本次对象、参考用途、必要内容与交付形式。用户尚未给定的分辨率、横竖比例、透明背景、九宫格和切片尺寸保持待定，结合具体截图和用途确定后写入该任务记录。

切片承接对应已确认整屏或原画的边框、颜色、材质和比例。需要透明时检查真实 alpha，不能用棋盘格伪装透明。原生图、裁切、缩放与导出分别记录。
