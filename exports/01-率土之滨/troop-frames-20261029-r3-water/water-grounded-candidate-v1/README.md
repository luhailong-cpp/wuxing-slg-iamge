# 水兵现有动作图配准候选

采用既有 water-idle-sheet-v2、attack/hurt/defeat-sheet-v1 四张原生 RGBA。本步未调用生成工具，未改原图或来源记录。待机4、攻击6、受击4、战败6，共20帧；native1024/normalized1024/map128h三套共60张派生PNG，各有独立derivation记录。

manifest.json 是唯一切片/配准入口。必须按逐帧sourceRect，不可等分自动切源图：待机行y650；攻击行y528，下排列x0/566/1072/1536，完整保留跨名义列线的环杖；受击行y644；战败行y590，保留上排越过y512的脚。

每帧脚/膝/坐姿支撑ROI均实际目视检查。战败3/4用膝，5用伸出靴底与折叠膝，6用可见裤腿支撑与前靴底；第6帧旁边流苏已排除，环杖/盾牌从未作为根点。身体接触投影的中点统一到1024画布(512,768)，每动作仅一个头盔标定比例(硬质头盔含耳板约180px)，没有逐帧fit。384派生根点(192,288)，建议Unity bottom-left normalized pivot(0.5,0.25)。

native1024完整保留每个来源矩形的RGBA字节，包括alpha1与透明RGB；缩小版用预乘Lanczos正常重采样，不做alpha清理。map128h是共享方法的历史层级名，水兵母版轮廓实高137px，不声称恰好128px；下蹲/坐姿保持自然高度。
