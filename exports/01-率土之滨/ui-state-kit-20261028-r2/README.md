# UI 状态素材 r2

本批为 3 张内置 image_gen 原生 RGBA sheet 和 23 个矩形切片候选。所有标签、正文、数量与按钮行为由客户端提供；本批没有整屏或烘焙中文数据。

| 原生 sheet | 实际尺寸 | 布局 | 导出 |
|---|---:|---|---:|
| 01-button-tab-state-sheet-v1 | 1536×1024 | 3列×3行：主按钮默认/按下/禁用；次按钮默认/按下/禁用；页签默认/选中/禁用 | 9 |
| 02-checkbox-toggle-state-sheet-v1 | 1774×887 | 4列×2行：勾选框关/开/禁用关/禁用开；开关关/开/禁用关/禁用开 | 8 |
| 03-feedback-frame-illustration-sheet-v1 | 1536×1024 | 3列×2行：确认/错误/空状态框体；对应独立插画 | 6 |

原生位于 `designs/01-率土之滨/assets/ui-state-kit-20261028-r2/`，逐张有 `.generation.json`。本目录 PNG 均是派生裁切，不是 23 张独立模型原生图。精确源坐标、SHA256、尺寸、派生侧车和状态含义见 `ui-state-kit-manifest.json` 与 `slice-table.json`。

按钮/页签切片为 512×224；勾选框为 444×352；开关为 444×288；反馈框与插画为 512×512。相同家族使用相同画布，但手绘轮廓并非逐像素一致。保留透明留白参与布局，避免每帧自动紧裁导致状态跳动。

默认以 Simple 固定尺寸或等比缩放使用。按钮/页签只给横向九宫格候选，原生高度 224 不拉伸；框体的双轴边界也仅是提案。左右角饰、玉珠及云纹应固定，纸纹与内框在目标尺寸仍须检查。具体 L/T/R/B 建议写在 manifest，`validatedInRuntime` 均为 false。图标、开关、勾选框不要九宫格拉伸。

真实透明度已检查，并看过所有切片的浅米/深玉底拼板。23 切片在 Alpha>8 的诊断阈值下没有边缘触碰；该阈值只用于检查，没有改写或删除像素。3 张原生图的低 Alpha 残留原样保留；01/03 最大 Alpha 为 254、没有 255，中心仍有轻微透明度。没有进行抠色、补画或透明度归一化。

禁用素材只表达外观，客户端仍须禁用输入。勾号与开关滑块已经画入各状态，动画过渡与拆层尚未制作。确认/错误/空状态框、图与按钮需要客户端组合；hover/focus/loading 等完整状态未覆盖。未启动 Unity、编译、重型处理或设备验收，均未获得用户批准。
