# 新人物UI候选

司马懿、夏侯惇、孙尚香、甄洛、大乔、小乔，各一张原生母稿与face-native、bust-native、avatar128、avatar256、card-full五规格，共30张派生。全部浅深底卡面/头像已实际查看，原尺寸窗口逐像素核对。

头像/半身是明确的矩形窗口，会截取长发、冠饰、器具；全身请用带透明留白的768×1024卡面。所有派生保留来源，缩小使用预乘Lanczos，不清除低alpha，不把边距补齐称为原生重绘。源alpha最大254、alpha1与不足8%余边等19项WARN见manifest。

它们是独立人物母稿候选，不等于该人物的全部卡牌变体，也不是Unity或用户最终验收。
