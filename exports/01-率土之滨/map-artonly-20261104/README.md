# 关隘粮道

[横屏地图美术](pass-supply-road.png)为 1254×706 RGB。关门石阶接入斜向粮道，沿线摆放麦田、木工坊、采石场和粮仓。草地从现用 1254×1254 原图按原像素裁切。石路和独立地物沿用现有美术，以记录中的比例缩小后分层摆放。共 14 层摆放，引用 9 张现有素材。

[装配与来源记录](pass-supply-road.png.derivation.json)提供每层源图路径、SHA256、原尺寸、摆放顺序、变换及实际可见范围。坐标原点在左上角。地面、石路、地物按顺序合成。关门脚下路径沿石阶转向，绕开右侧石块，然后沿石路到粮仓旁。粮仓庭院入口仍需单独铺设。

[脚点与接缝检查图](../../../records/map-artonly-20261104/pass-supply-road-placement-proof.png)按金兵、木兵各一张现用待机帧的脚点放置，用于检查比例和落脚。成图和检查图均已实际查看。记录内包含 170 个路面色样检查点，每个点至少有 42/49 像素符合暖灰石板取样条件。地图碰撞、地图区块坐标和粮仓庭院入口仍待制作。

[渲染脚本](../../../records/map-artonly-20261104/render-sector.py)读取现有源图，校验哈希和画幅边界后生成装配成图及检查图。当前关隘粮道只覆盖一个示范片区，全世界沿用 750×750 格生产合同。
